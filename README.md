# Edibest Construction website

A mobile-responsive brochure website for Edibest Construction, using the supplied banner as a visual reference and hero asset.

## Sections

- Hero and brand introduction
- About / positioning
- Construction, design, maintenance and remodelling services
- Working approach
- Contact details and WhatsApp CTA
- Footer credit: Website built with love by webarastudio.com

## Important

The site uses only details visible in the supplied reference material. Project history, testimonials, location, pricing and technical claims have not been invented. These can be added once confirmed by Edibest Construction.

## Run locally

```bash
python3 -m http.server 4198
```

Open http://localhost:4198.
